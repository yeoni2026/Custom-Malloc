#Custom Mini Malloc

C 표준 라이브러리의 `malloc()`, `free()` 함수를 직접 구현한 프로젝트입니다.

## 핵심 설계
 
- 메모리 할당
    - `sbrk()`로 힙 영역을 늘려 메모리를 확보합니다.
    - 요청된 크기보다 크게 남는 블록은 필요한 만큼 쪼개서 사용합니다 (Split).
    - 블록 앞 8바이트 헤더에 크기 정보를 기록하고, 실제 데이터 영역의 주소를 반환합니다.
- 재사용 및 관리
    - 해제된 블록은 자기 자신을 노드로 삼아, 주소 순으로 정렬된 연결 리스트(Free List)에 연결됩니다.
    - 탐색 시 조건에 맞는 첫 번째 블록을 선택합니다 (First-fit).
    - 해제 시 양옆에 비어있는 블록이 있다면 하나로 합쳐 메모리 파편화를 막습니다 (Coalescing).
- 안정성 및 예외 처리
    - 블록 크기를 짝수 단위로 맞춰서, Split 후 남는 조각도 항상 리스트 노드(= 블럭 2개)로 쓸 수 있는 크기가 되도록 합니다.
    - `size == 0`, `free(NULL)`, 기본적인 중복 해제(Double Free), 메모리 부족 상황을 예외 처리합니다.

## 테스트
 
`test.c`에서 다음을 검증합니다:
1. `free(NULL)` 및 중복 `free()` 방어
2. 여러 블록 free 시 인접 블록 coalescing
3. 사이즈가 큰 요청이 들어올 때, 충분히 큰 해제 블록을 찾아 split하는지 검증

`print_free_list()`로 현재 free list의 순서, 각 요소들의 주소와 블록 크기를 확인할 수 있습니다.
